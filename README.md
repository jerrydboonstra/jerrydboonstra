**Start here:** [neckbeard](https://github.com/jerrydboonstra/neckbeard) reads a Claude Code plugin, skill pack or rule file before you install it, and tests its own claims hard. It's public and MIT-licensed. The [case study](https://jerryboonstra.com/work/neckbeard/) has the details.

[imagegen](https://github.com/jerrydboonstra/imagegen) lets Claude Code make and edit images through Codex CLI's image generator, on your own ChatGPT login. An edit can change one region and leave every other pixel as it was, for PNG or lossless WebP originals. It's public and MIT-licensed.

[remote-session](https://github.com/jerrydboonstra/remote-session) lets one Claude Code session start, message, watch and stop another on a second machine, over ssh. The other session runs in tmux, so a long job keeps going while your laptop sleeps. It's public and Apache-2.0 licensed.

[testslot](https://github.com/jerrydboonstra/testslot) lets people, agents and CI jobs share one machine for their test suites: each run waits for free cpus before it starts. It also works for one account on one laptop. It's public and MIT-licensed.
